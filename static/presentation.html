Adversarial NLI — Round 2

Multi-class classification on one of the hardest NLI benchmarks. End-to-end ML pipeline from EDA through Docker deployment.

The Task

Given a premise (factual passage) and a hypothesis, predict one of three labels: entailment, neutral, or contradiction.

Why ANLI R2 is Hard

Unlike standard NLI datasets (SNLI, MNLI), ANLI was collected via an adversarial human-and-model-in-the-loop process called HAMLET. In Round 2, human annotators wrote hypotheses specifically designed to fool a RoBERTa ensemble trained on SNLI + MNLI + FEVER-NLI + Round 1. Only examples the model got wrong made it into the dataset.

Key Implication

Surface-level heuristics (lexical overlap, negation keywords) are unreliable. The dataset requires genuine language understanding and reasoning.

Exploratory Data Analysis

Understanding dataset structure, distributions, and linguistic patterns to inform modeling decisions.

Label Distribution

The dev and test sets are perfectly balanced (~33.3% each class), but the training set is notably imbalanced: neutral dominates at 46.1%, followed by entailment at 31.8%, with contradiction underrepresented at 22.1%. This imbalance is a natural artifact of the adversarial collection — annotators found it easier to write hypotheses that models misclassify as neutral. This is worth noting for training strategies like class weighting or stratified sampling.

Fig 1 — Label distribution across train, dev, and test splits.

Text Length & Tokenization

Premises are substantially longer than hypotheses (median 54 vs 9 words), with a combined median of 64 words and 95th percentile at 80 words. Using the actual DeBERTa-v3 SentencePiece tokenizer, we found that 95%+ of premise-hypothesis pairs fit within 256 subword tokens. This informed our max_length=256 choice — saving ~50% memory vs the default 512 with minimal truncation. Text lengths are also consistent across all three classes, ruling out length as a discriminative feature.

Fig 2 — DeBERTa-v3 token length distribution with max_length cutoffs.

Lexical Overlap Analysis

In standard NLI datasets like SNLI, high word overlap between premise and hypothesis strongly predicts entailment. We computed Jaccard similarity per class and found the distributions almost completely overlap — lexical similarity carries no signal in ANLI R2.

Fig 3 — Jaccard similarity distributions by class. Near-complete overlap confirms surface features are uninformative.

Linguistic Phenomena

We tagged hypotheses by reasoning type: negation, numerical, quantifier, temporal, and comparative. Numerical reasoning is by far the most common, appearing in ~29% of entailment and ~33% of contradiction hypotheses. Contradiction hypotheses also show elevated negation rates (~14% vs ~7% for neutral), suggesting annotators frequently used numerical comparisons and negation to construct adversarial examples. This framework feeds directly into the error analysis in Section 05.

Fig 4 — Distribution of linguistic phenomena across training hypotheses.

Feature Correlation

The correlation matrix confirms what the individual analyses suggest: no engineered feature is meaningfully correlated with the label. The highest label correlation is just 0.07 (negation), with Jaccard similarity at 0.05 and all others near zero. This is the quantitative proof that ANLI R2's adversarial construction successfully neutralized the surface-level shortcuts that plague earlier NLI datasets.

Fig 5 — Feature correlation matrix. Label column shows near-zero correlation with all engineered features.
EDA Takeaways

Train set is imbalanced (neutral 46.1%, contradiction only 22.1%) — may hurt contradiction recall. Premise median 54 words, hypothesis median 9 words; 256 tokens covers 95%+ with no per-class length bias. Lexical overlap is uninformative across all classes → bag-of-words models will fail. Numerical reasoning dominates (~30%), with contradiction hypotheses showing elevated negation (~14%). No engineered feature correlates with the label above 0.07 → a powerful contextual model is required.

Key Finding

The model uses neutral as a "safe default" when uncertain — inflating neutral recall (60%) at the expense of contradiction recall (50%). 29% of true contradictions are misclassified as entailment, suggesting the model misses logical reversals when premise and hypothesis share semantic content.

Critical Finding

Every phenomenon has an error rate above 40%. Quantifier reasoning is hardest (50.9%) — words like "all", "some", "none" require precise logical scope reasoning. Surface-level examples (48.2%) are nearly as hard, indicating adversarial examples exploit reasoning beyond our regex-based categories.

Conclusions & Future Work

Summary of findings and directions for improvement.

What We Achieved

  • End-to-end ML pipeline from EDA through containerized deployment
  • 54.6% accuracy on ANLI R2 — 21+ points above random on adversarial data
  • Deep error analysis revealing systematic failure modes
  • Production-ready Docker deployment with REST API and interactive web UI

Limitations

  • 54.6% is well below human performance (~86%)
  • Model confidence is poorly calibrated on adversarial examples
  • Contradiction recall is only 50% — half of contradictions missed
  • No world knowledge or geographic reasoning capability

Future Directions

  • Confidence calibration — temperature scaling to make probabilities reliable
  • DeBERTa-v3-large — 304M params, expected ~58–61% on R2
  • Seed ensemble — average 3–5 models for +1–2% accuracy
  • Targeted augmentation — LLM-generated quantifier/numerical examples
  • Hybrid reasoning — symbolic module for quantifiers and arithmetic
