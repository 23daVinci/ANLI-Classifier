Adversarial NLI — Round 2

Multi-class classification on one of the hardest NLI benchmarks. End-to-end ML pipeline from EDA through Docker deployment.

The Task

Given a premise and a hypothesis, predict one of three labels: entailment, neutral, or contradiction.

Why ANLI R2 is Hard

ANLI was collected via HAMLET — a human-and-model-in-the-loop adversarial process. In Round 2, annotators wrote hypotheses designed to fool a RoBERTa ensemble trained on SNLI + MNLI + FEVER-NLI + Round 1. Only examples the model got wrong entered the dataset, making surface-level heuristics unreliable and demanding genuine language understanding.

Exploratory Data Analysis

Understanding dataset structure and linguistic patterns to inform modeling decisions.

Label Distribution

Dev and test are balanced (~33.3% each), but train is imbalanced: neutral 46.1%, entailment 31.8%, contradiction 22.1% — a natural artifact of the adversarial collection where neutral was easiest to fool models on.

Fig 1 — Label distribution across splits. Train imbalance may hurt contradiction recall.

Tokenization & Length

Premises are long (median 54 words), hypotheses short (median 9). Using the DeBERTa-v3 SentencePiece tokenizer, 95%+ of pairs fit within 256 tokens — informing our max_length=256 choice and saving ~50% memory vs 512. Text lengths are consistent across classes, ruling out length as a discriminative feature.

Fig 2 — DeBERTa-v3 token lengths. 256 covers 95%+ with no per-class bias.

Lexical Overlap

Jaccard similarity distributions nearly completely overlap across classes — lexical similarity carries no signal in ANLI R2, unlike SNLI where high overlap strongly predicts entailment.

Fig 3 — Jaccard similarity by class. Near-complete overlap confirms surface features are uninformative.

Linguistic Phenomena & Feature Correlation

Numerical reasoning is most common (~29–33% of hypotheses). Contradiction hypotheses show elevated negation (~14% vs ~7% for neutral). Despite this, the correlation matrix shows no engineered feature correlates with the label above 0.07 — quantitative proof that ANLI R2's adversarial design neutralized surface-level shortcuts.

Fig 4 — Linguistic phenomena distribution. Numerical reasoning dominates across all classes.
Fig 5 — Feature correlation matrix. All features show near-zero label correlation.
EDA Takeaways

Train imbalance (neutral 46.1%, contradiction 22.1%) may hurt contradiction recall. 256 tokens covers 95%+. Lexical overlap is uninformative. No engineered feature correlates with the label → a powerful contextual model is required.

Hybrid Routing

Confidence-based routing to a reasoning LLM for low-confidence predictions. DeBERTa-v3-large + Qwen2.5-72B-Instruct via HuggingFace Inference API.

Motivation

The error analysis revealed two problems: DeBERTa makes overconfident errors (58% above 90%), and it lacks world knowledge and complex reasoning. A reasoning LLM has complementary strengths -- broad knowledge, chain-of-thought inference -- but is slower and less NLI-tuned. The hybrid approach uses each model where it's strongest.

Architecture

Primary ModelDeBERTa-v3-large (304M, ~1.2s inference)

Routing LogicIf DeBERTa confidence < threshold, route to LLM
FallbackOn LLM failure, return DeBERTa prediction

Key Result

At threshold 0.95, the hybrid system routes 27.5% of predictions to the LLM and achieves 72.1% accuracy -- a +3.9% improvement over DeBERTa-v3-large alone. The LLM consistently outperforms DeBERTa on routed examples (65.5% vs 51.3%), validating the complementary strengths hypothesis.

Where Hybrid Helps vs Hurts

The routing is not perfect. The LLM corrects many DeBERTa errors but also occasionally overrides correct predictions. The net gain comes from the LLM being substantially better than DeBERTa on the uncertain subset.

Limitations of Hybrid Routing

The approach has three key limitations, each illustrated by real test cases:

LimitationExampleWhat Happens
Overconfident errors "Muccan Station is on the radio" (true: C) DeBERTa says neutral at 99.9% -- never routed
LLM also wrong "Born south of Dallas" (true: E) Both models lack geographic reasoning
Latency cost Any routed example +3-8s per prediction via API
Honest Assessment

58% of DeBERTa's errors are above 90% confidence and never get routed. The hybrid approach improves accuracy on the uncertain tail but cannot fix the fundamental calibration problem. Temperature scaling or ensemble methods would be needed to address overconfident errors.

Conclusions & Future Work

Summary of findings and directions for improvement.

What We Achieved

  • End-to-end ML pipeline: EDA, baselines, model evaluation, error analysis, hybrid routing, Docker deployment
  • 72.1% test accuracy with hybrid routing (DeBERTa-v3-large + Qwen-72B) -- 38.8 points above random
  • Scaling study: random (33%) to TF-IDF (42.5%) to BERT (43.5%) to DeBERTa base (54.6%) to large (68.2%) to hybrid (72.1%)
  • Deep error analysis across 6 linguistic phenomena with confidence calibration study
  • Novel hybrid routing system with configurable threshold and chain-of-thought reasoning display
  • Production-ready Docker deployment with REST API, model switching, and interactive web UI

Limitations

  • 72.1% remains below human performance (~86%) -- a 14-point gap
  • 58% of DeBERTa errors are overconfident (>90%) and bypass routing
  • LLM routing adds 3-8s latency per routed prediction
  • Both models fail on word-sense disambiguation and some geographic reasoning

Future Directions

  • Confidence calibration -- temperature scaling to make more errors routable
  • Seed ensemble -- average 3-5 DeBERTa-v3-large for +1-2%
  • Smarter routing -- train a meta-classifier to decide when to route (beyond just confidence)
  • Targeted augmentation -- LLM-generated quantifier/numerical examples for fine-tuning
  • Local LLM deployment -- distilled reasoning model for lower latency
